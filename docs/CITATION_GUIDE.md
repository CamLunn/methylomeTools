# Citation

Software citation information is available in R:

```r
citation("methylomeTools")
```

`CITATION.cff` supplies the software citation displayed by GitHub. The package
citation is also stored in `inst/CITATION`.

Research attribution includes the underlying methods used in an analysis,
including sva, DSS, ENmix, and annotation resources where applicable.
The standard MIT license governs reuse; citation requests do not add conditions
to the license.
